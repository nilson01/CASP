# Data

## Simulations

Simulation data are generated by the scripts in `src/casp_sim/`; no external simulation dataset is required.

## MovieLens 1M

The reconstructed application uses the official MovieLens 1M release from GroupLens.

Place the raw archive here:

```text
data/raw/ml-1m.zip
```

or place the extracted files here:

```text
data/raw/ml-1m/users.dat
data/raw/ml-1m/movies.dat
data/raw/ml-1m/ratings.dat
```

Then run:

```bash
bash scripts/run_main_application.sh
```

The preprocessing step constructs chronological request contexts, excludes already-seen items from feasible sets, derives binary rewards using `rating >= 4`, and writes processed artifacts under `data/processed/`.

MovieLens ratings are observational and missing-not-at-random. The application is therefore a reconstructed semi-synthetic evaluation, not a native randomized logging dataset.
